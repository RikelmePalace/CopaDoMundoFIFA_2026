# 🌎 Copa do Mundo 2026 — Resultados

Aplicação web em HTML, CSS e JavaScript para consultar os resultados da Copa do Mundo FIFA 2026.

## ✨ Atualização

O projeto foi atualizado após o encerramento da competição para substituir os placares `"?"` pelos resultados realizados.

Agora ele reúne:
- ⚽ 72 partidas da fase de grupos;
- 🏆 16 partidas dos 32-avos de final;
- ⚽ 8 oitavas de final;
- 🏆 4 quartas de final;
- 🔥 2 semifinais;
- 🥉 disputa do 3º lugar;
- 🏆 final;
- 🥅 indicação de prorrogação e disputa por pênaltis quando aplicável;
- 🔎 busca por seleção, data ou fase.

## 🏆 Resultado final

- 🥇 Espanha — campeã
- 🥈 Argentina — vice-campeã
- 🥉 Inglaterra — 3º lugar
- 4º França

A final terminou **Espanha 1 x 0 Argentina**, após prorrogação, em 19/07/2026.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript
- Vercel

## ▶️ Como executar

Abra `index.html` em um navegador ou publique os arquivos em um serviço de hospedagem estática.

## 📚 Fonte dos resultados

Os resultados foram conferidos na página oficial da FIFA sobre a tabela, resultados e fases da Copa do Mundo 2026.
